
# Smart Notice Banner

A lightweight and customizable WordPress announcement banner plugin built to display important notifications, promotional offers, and call-to-action messages across WordPress websites.

Designed with simplicity, performance, and flexibility in mind. The plugin allows website administrators to manage announcement banners directly from the WordPress dashboard without editing code.

---

## Project Overview

Smart Notice Banner is a custom WordPress plugin developed using PHP, JavaScript, and CSS.

It provides an easy way to display announcements, special offers, website updates, and promotional messages while maintaining a clean and responsive user experience.

## Structure

```text
smart-notice-banner/
├── smart-notice-banner.php   # Main WordPress plugin file

└── LICENSE                   # License information
```

## Features

- **Custom Announcement Banner:** Display important notices, promotional messages, and website announcements.
- **Admin Configuration:** Manage banner settings from the WordPress dashboard.
- **Customizable Design:** Configure banner text, background colors, and appearance.
- **Call-to-Action Button:** Add a clickable button to direct visitors to a custom URL.
- **Dismissible Banner:** Allow visitors to close the announcement banner.
- **Responsive Layout:** Designed for desktop, tablet, and mobile devices.
- **Shortcode Integration:** Insert the banner into WordPress pages or posts.
- **Lightweight Architecture:** Built using PHP, CSS, and vanilla JavaScript.

## Technologies Used

## Installation

1. Download the plugin ZIP file.
2. Log in to your WordPress Admin Dashboard.
3. Navigate to **Plugins > Add New Plugin > Upload Plugin**.
4. Select the ZIP file and click **Install Now**.
5. Activate **Smart Notice Banner**.
6. Open the plugin settings to configure your announcement.

## Shortcode Usage

Insert the following shortcode into a page or post:

```text
[smart_notice_banner]
```
